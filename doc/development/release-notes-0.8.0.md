MD2Word 0.8.0 adds a development-only Browser Review Mode. Running `npm run dev` opens the same React interface in a browser through a loopback Bridge to the real Electron Main services and C# Word Worker. The separate mock mode remains available for unusual UI states. The production Renderer and packaged application exclude the Bridge and do not open a local review server.

The desktop conversion protocol and user template storage behavior are unchanged from 0.7.0. A synthetic Markdown → Browser Review → Electron Main → C# Worker → Word conversion, template management, and the five-page interface were checked on a Windows host. Production bundle checks verify that the Bridge is excluded.

Windows x64 downloads include a Portable ZIP and Setup installer with the offline template authoring guide. A local 0.7.0 → 0.8.0 Setup upgrade preserved the synthetic user template files and default selection; the packaged Portable app also completed a synthetic Word conversion with lists, Mermaid, and captions. Microsoft Word desktop and Pandoc are required for conversion. Updates remain manual; close MD2Word before installing a newer Setup or replacing a Portable directory. Packages are unsigned. GitHub Actions compiles and tests without Word COM; the real Word and installer checks were performed separately on a Windows host.
